WOULD — Log Document Guide

============================================================
WHAT THIS IS
============================================================
WOULD/ contains the activity log for this project.
LOG-2026Q3.md is a running chronological record of decisions,
changes, and notable events for the quarter.

============================================================
LOG DOCUMENT RULES (for AI models and contributors)
============================================================
- Always add new log entries at the top, directly below the
  anchor marker line.
- Never delete or edit previous log entries.
- One entry per meaningful action or decision.
- Entry format:  ## LOG:<subject> <YYYY-MM-DD HH:MM>

============================================================
WHEN TO LOG
============================================================
- New content batch generated
- Media created or updated
- CSV structural changes (new columns, new weeks)
- Tree doc updated
- Feedback received from client
- Any decision that affects publishing scope or timing
