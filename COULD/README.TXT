============================================================
WHAT THIS IS
============================================================
COULD/ contains the asset log for this project.
ASSET-2026Q3.md is a running record of all created assets —
media files, research outputs, structural changes, and anything
that needs a status or verify note attached to it.

============================================================
ASSET DOCUMENT RULES (for AI models and contributors)
============================================================
- Always add new asset entries at the top, directly below the
  anchor marker line.
- Never delete or edit previous asset entries.
- Entry format:  ## ASSET:<subject> <YYYY-MM-DD HH:MM>

============================================================
WHEN TO LOG AN ASSET
============================================================
- New media file generated (image, PDF, graphic)
- CSV updated with new posts or columns
- Research output saved to the repo
- Any file that has a status (READY / BLOCKED / VERIFY)
- Decisions about what was kept out of media or copy
